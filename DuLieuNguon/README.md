# Dữ liệu nguồn

- Chung/: quy định LMS, hướng dẫn giảng viên và tài liệu chung.
- ex01/ đến ex04/: đề, ảnh mẫu, tài nguyên và phản hồi của từng bài.
- Bài mới: tạo tiếp ex05/, ex06/... tương ứng.

## Tài liệu đã nhận

Chưa tìm thấy đề gốc hoặc tài liệu yêu cầu riêng trong hai bản repository đã kiểm tra. Các ảnh trong ex02/images và ex03/images là tài nguyên sản phẩm hiện có, được giữ nguyên.

Toàn bộ nội dung đầu vào mặc định chỉ lưu local và bị Git bỏ qua; chỉ README này được quản lý phiên bản. Trước khi đưa tài liệu lên Git phải xác minh quyền chia sẻ. Ảnh để chạy sản phẩm phải sao chép vào exNN/images/, không liên kết sang đây.

Bài tiếp theo: ex04. Cần đề đầy đủ, ảnh mẫu, tài nguyên được cung cấp và quy định nộp LMS.
